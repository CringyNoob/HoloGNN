Executive SummaryThis project presents Holo-GNN, a novel deep learning architecture designed to bridge the gap between 1D protein sequences and 3D structural biology. Unlike traditional language models that treat proteins as simple text, Holo-GNN dynamically constructs a graph representation of the protein in real-time, allowing it to "see" the 3D geometry without requiring expensive crystal structure files (PDBs).The model was trained in two phases:Physics Pre-training: Learning the laws of protein stability ($\Delta G$) on 100,000+ sequences.Medical Transfer Learning: Applying this physical "knowledge" to diagnose pathogenic mutations.Key Result: The model achieved a ROC-AUC of 0.84 in distinguishing pathogenic variants, validating that physics-aware pre-training significantly improves performance on downstream medical tasks.2. Problem StatementThe Challenge:In bioinformatics, predicting whether a mutation causes disease is difficult because proteins are complex 3D objects.Sequence Models (1D): Treat amino acids like letters in a sentence. They miss long-range interactions (e.g., two residues far apart in sequence but touching in 3D space).Structural Models (3D): Require experimental structures (PDB files), which are unavailable for many mutations.The Solution:Holo-GNN acts as a "Holographic" bridge. It takes a simple sequence as input but mathematically projects it into a 3D Graph structure using Attention Maps, enabling the model to reason about geometry without needing external structure files.3. Methodology: How It Works3.1 The ArchitectureThe Holo-GNN consists of three distinct modules:The Sequence Module (Tokenizer):Uses the ESM-2 (Evolutionary Scale Modeling) tokenizer to convert amino acids into numerical vectors.The Structural Module (The "Holo" Backbone):Graph Construction: Instead of using static edges, the model dynamically creates edges between amino acids based on their Attention Scores. If Amino Acid A "pays attention" to Amino Acid B, an edge is drawn, simulating a physical 3D contact.GNN Layers: Graph Attention Networks (GATv2) process this graph, aggregating information from "neighboring" amino acids in 3D space.The Task Heads:Stability Head: A regression layer predicting $\Delta G$ (Gibbs Free Energy).Proteomics Head: A classification layer predicting Pathogenicity (0 or 1).3.2 Training StrategyTo overcome hardware limitations (GTX 1050 Ti, 4GB VRAM), a Gradient Accumulation strategy was employed, simulating a batch size of 32 on hardware that could only handle 4.Phase 1: Physics Pre-trainingDataset: Tsuboyama et al. (Mega-scale deep mutational scanning).Goal: Predict protein stability ($\Delta G$).Logic: By learning stability, the GNN backbone is forced to learn "Protein Physics" (e.g., hydrophobic packing, steric clashes).Phase 2: Transfer Learning (The "Helix Breaker" Experiment)Dataset: Synthetic variant set simulating the biological "Helix Breaker" rule (Proline mutations in helices are pathogenic).Goal: Classify variants as Benign (0) or Pathogenic (1).Logic: The backbone weights were frozen. Only the final classification head was trained, proving that the pre-trained "physics brain" could solve medical problems.4.
